# HTML을 이용한 정적 블로그 제작

## 프로젝트 개요

HTML과 CSS를 이용하여 간단한 정적 블로그를 제작하고 GitHub Pages를 통해 배포함.

---

## 1. GitHub 저장소 생성

GitHub에서 블로그 프로젝트를 위한 저장소를 생성함.

저장소를 로컬 환경으로 clone한 후 Visual Studio Code에서 프로젝트를 열어 개발을 시작함.

---

## 2. 프로젝트 구조 생성

블로그를 구성하기 위해 다음과 같이 프로젝트 구조를 생성함.

```text
.
├── index.html
├── about.html
├── posts
│   └── first-post.html
└── style.css
```

`posts` 폴더는 게시글을 관리하기 위해 생성하였으며, 스타일은 하나의 CSS 파일에서 관리하도록 구성함.

---

## 3. 메인 페이지 작성

`index.html` 파일을 생성한 후 HTML의 기본 문서 구조를 작성함.

블로그 제목과 간단한 소개를 추가하고 About 페이지와 게시글 페이지로 이동할 수 있도록 링크를 작성함.

---

## 4. About 페이지 작성

`about.html` 파일을 생성하여 자기소개와 블로그의 목적을 작성함.

메인 페이지로 이동할 수 있는 링크도 함께 추가함.

---

## 5. 첫 번째 게시글 작성

`posts` 폴더에 `first-post.html` 파일을 생성함.

게시글 제목과 본문을 작성하고 메인 페이지에서 해당 게시글로 이동할 수 있도록 링크를 연결함.

---

## 6. CSS 적용

`style.css` 파일을 생성한 후 모든 HTML 파일에서 동일한 스타일을 사용할 수 있도록 연결함.

글꼴, 배경색, 제목 스타일, 링크 색상 등을 수정하여 전체적인 디자인을 통일함.

---

## 7. GitHub Pages 설정

프로젝트를 GitHub 저장소에 업로드한 후 GitHub Pages를 활성화함.

배포가 완료된 후 생성된 URL로 접속하여 정상적으로 페이지가 표시되는지 확인함.

배포 이후 HTML 파일을 수정하고 다시 push하면 변경 사항이 반영되는 것도 확인함.

---

## 마무리

이번 프로젝트에서는 HTML과 CSS를 이용하여 정적 블로그를 직접 제작하고 GitHub Pages를 통해 배포하는 과정을 수행함.

게시글을 작성할 때마다 새로운 HTML 파일을 직접 생성해야 한다는 점은 다소 번거로웠지만, 웹 페이지의 기본 구조와 GitHub Pages를 이용한 배포 과정을 이해하는 데 도움이 되었음.

Solution으로서 jekyll을 이용하여 GitBlog를 만듦. 구현된 Web pages는 jekyll을 이용한 것.
