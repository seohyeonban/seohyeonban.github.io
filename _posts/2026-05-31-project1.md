# 금융 웹 프로젝트 - 로그인 화면 구현

## 프로젝트 개요

HTML 학습을 위해 금융 서비스를 주제로 프로젝트를 진행하기로 계획함.

처음부터 복잡한 기능을 구현하기보다 로그인과 회원가입 기능부터 구현한 후 점차 금융 서비스의 기능을 추가하는 방식으로 개발을 진행하기로 결정함.

---

## 프로젝트 기획

프로젝트를 시작하기 전 구현할 기능을 먼저 정리함.

- 로그인
- 회원가입
- 로그아웃
- 가상 계좌 생성
- 가상 잔액 조회
- 가상 송금

이후 필요한 화면도 함께 계획함.

- 홈 화면
- 내 계좌 화면
- 잔액 조회 화면
- 거래내역 화면
- 수신자 입력 화면
- 송금 확인 화면

또한 Firebase를 이용한 데이터베이스 구조와 보안 규칙까지 적용하는 것을 목표로 설정함.

---

## UI 참고

금융 서비스의 UI를 구현하기 위해 토스증권 클론 프로젝트와 토스에서 공개한 프론트엔드 저장소를 참고함.

실제 금융 서비스에서 사용하는 화면 구성을 확인하고 필요한 UI 요소를 분석함.

---

## 로그인 화면 구현

프로젝트의 첫 번째 단계로 로그인 화면을 구현함.

HTML 문서를 생성한 후 로그인 화면의 기본 구조를 작성함.

`form` 태그를 이용하여 입력 폼을 구성하고 `fieldset`과 `legend`를 사용하여 로그인 영역을 구분함.

---

## 입력 항목 작성

사용자로부터 입력받을 정보를 다음과 같이 구성함.

- 이름
- 생년월일 6자리
- 휴대폰 번호
- 연락처

입력 편의성을 위해 `placeholder`를 적용하고 첫 번째 입력란에는 `autofocus`를 설정함.

---

## 약관 동의 항목 추가

실제 금융 서비스와 유사한 화면을 구성하기 위해 체크박스를 추가함.

다음 항목을 구현함.

- 필수 약관 동의
- 개인정보 수집 및 이용 동의
- 개인정보 제3자 제공 동의

---

## 로그인 버튼 추가

모든 입력이 완료된 후 로그인을 진행할 수 있도록 Submit 버튼을 추가함.

현재 단계에서는 화면만 구현하였으며 실제 로그인 기능은 구현하지 않음.

---

## CSS 적용

HTML과 CSS를 분리하기 위해 별도의 `login.css` 파일을 생성함.

로그인 화면의 레이아웃과 디자인은 CSS에서 관리하도록 구성함.

---

## 구현 결과

HTML Form을 이용하여 로그인 화면의 기본 UI를 구현함.

실제 금융 서비스에서 사용하는 입력 화면과 유사한 형태로 구성함.

현재는 화면만 구현한 상태이며 데이터 검증과 로그인 기능은 아직 구현하지 않음.

---

## 향후 계획

다음 단계에서는 회원가입 화면을 구현할 예정임.

이후 Firebase Authentication과 Firestore를 연동하여 실제 로그인 기능과 사용자 데이터를 관리할 계획임.

로그인 기능 구현 이후에는 가상 계좌 생성, 잔액 조회, 송금 기능 등을 순차적으로 개발할 예정.
